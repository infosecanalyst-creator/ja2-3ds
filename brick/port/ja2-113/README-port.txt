Jagged Alliance 2 v1.13 on the TrimUI Brick
===========================================
Engine : 1vibe13 v0.10.0-alpha1 (SDL3 port of JA2 1.13), built for the Brick
         (aarch64, glibc 2.23) with a framebuffer video driver added to SDL3.
Data   : JA2 Gold (Steam) + JA2 1.13 v5, copied by "Install JA2 1.13 to Brick.bat".
Screen : 1024x768 (Ja2.ini SCREEN_RESOLUTION = 5) - the Brick's native panel.

Controls
  D-pad ........ move the mouse cursor (hold L1 for slow / precise)
  A ............ left click            B ........... right click
  X ............ Space (next merc / map: pause time)
  Y ............ M (strategic map)
  R1 / L2 ...... Page Up / Page Down (stance up / down, climb roofs)
  R2 ........... D (end turn)
  Start ........ Esc (cancel; on the map, enter the sector)
  Select+Start . quit (PortMaster hotkey)
  Text entry (IMP name etc.): PortMaster on-screen text input via the hotkey.

Troubleshooting: log.txt in this folder is rewritten on every launch.
